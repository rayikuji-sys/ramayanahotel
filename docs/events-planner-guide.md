# Panduan tamu: menyusun layout acara

1. Buka Events → Request proposal, isi tanggal/jumlah peserta, dan pilih venue.
2. Pilih **Buat layout sendiri**. Planner terbuka pada venue pilihan Anda.
3. Pilih **Rapat + panel** untuk membuat kursi peserta beserta meja/kursi narasumber dan moderator. Preset Theatre, Classroom, Round tables, dan U-shape juga tersedia.
4. Pada tab **Furniture**, tambahkan set narasumber (1 meja + 2 kursi) atau moderator (1 meja + 1 kursi). Penempatan baru mencari area kosong.
5. Geser meja. Ketika sisi meja searah didekatkan dan ruang sambungannya kosong, **Magnet meja** menempelkan meja dan menggabungkannya sebagai satu grup. Tombol **Sambungkan meja terdekat** di tab Edit juga tersedia. Meja bundar tidak memakai sambungan sisi.
6. Grup digeser bersama dengan kursinya. Pilih **Pisahkan grup** untuk mengatur komponennya sendiri. Perubahan peran pada grup berlaku untuk semua komponennya.
7. Warna emas / N = narasumber; biru / M = moderator; abu-abu = peserta. Penghitungan kursi peserta tidak memasukkan kursi narasumber/moderator.
8. Pada ponsel, gunakan daftar **Pilih objek** dan tombol panah untuk pemindahan yang lebih tepat. Undo/Redo tersedia. **Smart Seating** menyusun ulang kursi satu meja; pisahkan grup meja yang tersambung sebelum menyusun ulang kursinya.
9. Klik **Simpan layout**, lanjutkan formulir, periksa ringkasannya, lalu kirim. Layout disimpan bersama permintaan dan dapat ditinjau staf melalui dashboard.

Ekspor PNG adalah salinan visual. Bukti pengisian setelah pengiriman memiliki nomor referensi serta detail lengkap dan dapat dicetak/disimpan PDF. Layout masih berupa konsep; ukuran nyata, kapasitas, akses, dan penempatan akhir perlu dikonfirmasi tim hotel.
